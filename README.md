## 本机开发与验收

请先准备被 Git 忽略的 `infra/competition/.env.local` 和本机运行配置。密钥不能写入源码或提交 Git。

在仓库根目录启动隔离依赖：

```bash
docker compose --env-file infra/competition/.env.local -f infra/competition/compose.yaml up -d
```

该命令仅启动 MySQL、Redis、RabbitMQ；前后端应用需单独启动。应用与依赖必须使用参赛专用配置，不能连接原项目的数据服务。

本机当前验收地址：

- 用户端：<http://127.0.0.1:13000/>
- 管理端：<http://127.0.0.1:13001/>
- 后端：<http://127.0.0.1:18080/>

账号由管理员创建，无自助注册入口。启动与验收步骤见 [本机简单验收](docs/competition/本机简单验收.md)，当前能力范围以较新的专项验收记录为准。

## 工程与检查

| 目录 | 用途 |
| --- | --- |
| `backend/` | Java 17、Spring Boot、MyBatis-Plus，Flyway V1–V39 |
| `frontend/` | React 19、TypeScript、Vite 用户端 |
| `frontend-admin/` | 独立管理端 |
| `infra/competition/` | 参赛隔离基础设施 |
| `docs/competition/` | 实施计划与验收证据 |

两端均使用 `pnpm test` 执行测试、`pnpm build` 执行类型检查及生产构建。后端使用 Maven；运行时需提供独立 MySQL、Redis、RabbitMQ 和供应商配置。真实上游验证与模拟测试的结果应分别记录。
