## 本次交付

- 用户端 `/brainstorm`：持久化创作需求、受控工具运行、多个结构化大纲方向、人工采用/编辑/选择理由/确认、转入既有文字创作、JSON 过程导出；原文字对话与历史仍位于 `/toolbox`。
- 管理端 `/knowledge`：来源、机构、日期、自动采集时间、摘要、事实/传说/演绎分类、主题、授权、有效期与审核。编辑撤销审核；历史修订和审核动作持久化；普通用户只能检索通过审核的条目，过期 FACT 不参与检索。
- 管理端 `/prompts`：不可变草稿、发布、停用、复制成新版本、历史查看、变量约束、作者/时间及并发发布保护。停用后不静默回退。已接受的任务保留原版本和实际请求快照。
- 受控工具仅允许 `search_knowledge`、`web_search`、`read_page`、`validate_sources`、`save_draft`、`ask_user`、`finish`。每运行冻结工具/页面/修复上限，硬上限为 8/5/2；没有 Shell、SQL 或任意网络权限。最多三个大纲方向，来源 ID 必须属于冻结资料。
- 外部网页经过固定 Firecrawl v2 服务，只有经过公开 HTTPS 校验的 URL 可传入；响应及资料长度受限。网页始终标记未经审核，缺少配置、服务失败或地址阻断会留下明确记录。网址可访问不代表事实成立，更不代表素材授权。
- 模型决策、工具输入与结果、拒绝原因、中间大纲及人工前后版本保存；未知受理状态不自动重发。重启未知执行转人工核对；本机恢复保留原 UUID 和账号边界。

## 真实文字与页面验收

隔离地址：用户端 `127.0.0.1:13000`，管理端 `127.0.0.1:13001`，后端 `127.0.0.1:18080`；数据库 `ai_board_competition`，队列 vhost `competition`，独立上传目录。恢复了中断期间停止的依赖与应用进程，没有操作原 Ai-board。

1. 通过管理 API 建立八仙过海资料，按 LEGEND 分类并保留来源和独立授权说明。编辑后从用户检索消失，重新审核后恢复；过期审核请求返回 40002，普通用户读取管理端返回 40103。浏览器再编辑摘要、保存待审核、填写意见并审核通过，最终知识条目 #1 修订 6。
2. 提示词创建和发布实际通过 API 与浏览器执行。错误的发布基准返回 40002。浏览器复制 v2 为 v3、编辑并发布成功。停用后新头脑风暴被拒绝（50004，无新增运行）；随后按不可变版本规则复制成 v4 恢复。旧运行继续保留 v2/v3。过期 FACT 测试条目不进入检索，测试后已驳回。
3. 真实使用官方 `deepseek-flash`。头脑风暴 #1 的运行 #1 使用提示词 v2，共 8 个模型决策，最终进入 NEEDS_REVIEW；保留失败记录，没有自动开启第二次运行。检查发现模型一次 JSON 未闭合、本机 Clash DNS 将公共域名返回为 `198.18.*` 保留地址、知识查询过于整句匹配；分别补了拒绝决策修复上下文、明确 BLOCKED 证据及分词匹配回归。
4. 人工在页面发起运行 #2，使用提示词 v3，6 个模型决策、4 次工具、2 次格式修复，最终 SUCCEEDED。真实工具记录包括 `validate_sources`、`web_search`（BLOCKED）、`save_draft`、`finish`。生成两个方向，引用冻结的 `knowledge-1-v6`，说明外网未取得，不将其伪装成审核资料。
5. 浏览器采用候选，选择第一方向；人工改标题、故事节点和采用/放弃理由，保存后确认到修订 4。页面转入创作草稿 #7，简报含选中方向、人工改动、理由及来源分类快照。重复承接仍返回 #7；其他用户读取返回 40004；旧候选再次采用返回 40002。
6. 草稿 #7 的真实剧本任务 #50、运行 #11 成功，输出 898 字符并已采用。正文含“民间传说改编/非史实”、协作节点、八人共同抵达及来源 ID。用页面核对了承接简报和实际剧本。之后重启，确认大纲、已采用剧本与管理员 v4 均保留。
7. 最终实际导出含 14 次模型决策的 system/user 请求快照、参数、供应商和用量，以及 5 条人工事件；品牌声明、需求、大纲、工具过程、来源快照与承接快照同时保留。数据访问均从所属用户校验开始，不公开其他用户的证据。
