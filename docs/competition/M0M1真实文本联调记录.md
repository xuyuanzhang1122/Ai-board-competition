## 真实联调发现并修复的问题

1. MiMo 默认思考会消耗受限输出：两种供应商均显式禁用思考。提交 `f548b1d`，回归测试先失败后通过。
2. 同步文本 API 返回费用 0，但任务 cost_points 没有赋值：持久化 ChargingResult 的用户费用。提交 `eb55296`。任务 3、4、5、6 已在真实 MySQL 证实为 0；较早任务 1、2 的 NULL 保留，不静默改写历史记录。
3. 工具箱历史仅查询旧 UsageCharge 表，免费任务没有账单而显示 NULL：优先读取任务费用，未知时才查询历史账单。提交 `8fb227d`。重启后历史任务 3、4、6 返回 0，旧未知记录保持 NULL。

免费策略不产生钱包扣费流水，本次 `usage_charges` 为 0 行；这与供应商用量、人民币预算记录分开保存。
