## 已确认的免费模式

用户明确选择参赛免费、记录真实模型用量并限制预算。生成策略现在返回用户积分费用零和 `COMPETITION_FREE`；移除了临时测试逻辑、虚拟余额 999999 和虚构的交易 ID。余额、流水 ID、使用扣费记录 ID 均为空，没有创建实际钱包流水。

前端生成入口显示“参赛免费”，不再展示积分预估；首页不请求钱包，钱包及充值链接直接返回首页。后端拒绝创建充值订单，套餐和兑换规则返回空列表，防止直接调用 API 绕过界面。历史支付查询、取消和回调仍保留供历史记录核对。历史任务中的非零积分标为历史费用，不改写数据。

**免费仅指用户积分费用为零，不代表供应商调用不花钱。** 供应商返回的 token 用量仍按文本任务记录；缺失用量保持 `usageKnown=false`，不能据兼容字段的零断言供应商成本为零。当前尚未实现持久化人民币预算预留与成本结算，价格和账户上限也尚未核验，因此新供应商继续默认关闭，未发起任何付费调用。后续按既有预算范围保守从 20 元上限开始，不能通过免费积分策略绕过预算关卡。

## 前端文本模型与请求行为

- 编辑器使用独立的 `competition_model_config_v1` 存储键，不读取、覆盖原项目的 `yuanmeng_model_config`。旧或格式不合法的文本选择清空，默认语言模型为空，不自动替换成另一项模型。
- 编辑器和工具箱共用目录过滤，校验候选代码、供应商、语言类型及启用标记。候选仅为 `deepseek-flash`、`deepseek-v4-pro`、`mimo-v2.6-pro`；存在于候选表不等于账户可用。
- 工具箱遇到空或失效的文本选择时要求用户重新选择，发送前检查选择仍在当前目录。图片/视频旧默认值与能力表继续留待媒体替换阶段迁移。
- 模型配置弹窗每次打开刷新目录；空目录不引发反复请求，显示暂无可用模型，并阻止保存失效语言选项。
- 角色/场景描述请求失败后不自动重发；立即取消的 effect 在微任务调度后停止提交，覆盖开发模式同一轮 setup/cleanup/setup 重放。该保护不能替代跨页面、跨进程的请求幂等和受理不明核对；手动重新提交仍可能产生新调用。

服务端生成路径尚需统一落实数据库启用标记、持久化预算及受理不明处理；前端筛选不能充当服务端授权或成本控制。当前供应商配置总开关关闭，不能只打开开关就宣称可发布。
