## 本轮确认的要求

用户明确要求文字生成不再受测试金额限制，模型目录必须来自新官方上游实际返回结果，用户端与管理端都不能继续展示旧模型。工具箱按用户提供的四张 ChatGPT 截图整体重构，不能保留无法适配的旧聊天组件；对话和任务必须由服务器持有，浏览器关闭后重新打开仍能恢复。

图片、视频的真实供应商调用继续关闭。新的媒体任务卡使用相同对话流结构，真实生成权限仍由用户准备，不能以界面完成冒充真实生图已接通。

## 新的对话与后台执行

V38 新建独立的服务器会话、消息表，客户端不再保存或回写整段 `conversationsJson` 作为权威历史。

1. 发送时锁定当前用户的会话，校验权限、类型和模型，将请求 ID、用户/助手消息对及 PENDING job 在同一事务中保存。
2. 相同请求 ID 与相同内容返回原任务，内容不一致则拒绝；同一会话串行生成。
3. 数据库后台轮询将已持久化任务送入有界执行器，现有条件认领 SQL 防止重复执行；与页面是否打开无关。
4. 上下文由服务器保存的成功消息构造，冻结结构化 user/assistant turns；新官方 provider 按真实角色数组发给上游，不接受浏览器伪造助手历史。
5. 任务结果、错误和真实用量由后台保存。前端只读取服务器会话状态，切换/关闭页面只停止观察，不停止后台执行。
6. 服务器进程重启时可恢复未执行的 PENDING；已为 RUNNING、供应商受理不明的调用标记需核对，不自动付费重发。停止展示不保证供应商停止计费。

新接口位于 `/api/toolbox/chat/sessions`；会话 URL 为 `/toolbox?session=<id>`。会话软删除不移除历史任务审计。

## 页面重构及最后修复

工具箱离开原主布局，使用独立窄导航栏、可展开搜索历史、居中空白输入框、固定底部输入区、淡蓝用户气泡、无外框助手 Markdown。旧 ChatList、旧聊天状态和不适配的侧栏/历史抽屉退出此页面。

新 `MediaTaskCard` 使用标题、白底方形画布、轻蓝加载状态、原比例结果与下载。只有真实进度字段存在时才显示百分比；当前后端无媒体进度，不编造 33%/88%。

审查发现并已修复：

- 退出/切换账户立即清空内存会话，未确认请求按账户隔离；晚到的旧账户响应不能覆盖新账户。
- 取消旧会话任务及在加载期间收到受理结果，不再使当前会话永久停在加载状态。
- HTTP 400 参数拒绝保留业务码，明确未受理时释放请求；网络/未知服务器错误保留同一请求 ID，避免误重发。
- 长输入保留原文并提示长度问题；模型拉取失败清空选择并阻止提交。

2026-10-20 浏览器实际验证：账户 A 的会话能恢复；退出 A、登录独立空账户 B 后打开相同 URL，显示“会话不存在”，不显示 A 的消息。B 提交被拒绝后草稿仍保留，发送按钮可用，没有被受理不明状态锁死。最后恢复 A 供查看真实结果。
