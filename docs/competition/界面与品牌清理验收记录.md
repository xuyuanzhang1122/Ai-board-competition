# 界面与品牌清理验收记录

日期：2026-10-20。

本轮按用户要求优先完成发送加载样式与可见品牌清理，未修改后台任务的执行、幂等、持久化和供应商调用协议。

## 对话加载

- 点击发送后，按钮立即显示呼吸圆点；禁止重复提交。
- 服务端消息为 PENDING / RUNNING 时，助手位置显示同一呼吸圆点与带可访问名称的停止图标，不显示“已提交”“等待处理”或“正在思考”等状态文字。
- 正常 sending 期间隐藏尚未确认受理的提示。真实失败、网络不确定状态及原请求重试仍保留。
- 加载圆点带 `role=status` 和可访问名称；尊重减少动态效果设置。

浏览器实际发送一次文字任务，服务端会话 10、任务 21。生成中截图确认无提交文字，刷新后可读取完成回复；接口查询确认助手消息 SUCCEEDED、完整内容 1181 字符。没有调用图片或视频生成。

## 品牌清理

登录页、首页、主侧栏、管理员登录页、管理端框架及两端浏览器标题改用参赛品牌。完整标识为：2026 山东省首届大学生 AI 大模型创新传播大赛 · 你的不对我的队；界面短名称为 AI 创作工作台。

两端 favicon 和用户端 logo 替换旧鹦鹉图标；通用创作入口使用无厂商品牌的图标。删除可见个人 GitHub 链接与创作者署名，同步整理 README，并保留必须保留的许可证声明。首页适配较长新名称，窄屏中声明与向下滚动提示不重叠。

浏览器核对了用户登录页、首页、工具箱、管理员登录页和模型目录。对两端 `src`、`public`、HTML 入口及 README 搜索旧品牌、个人署名、个人 GitHub 标识，未发现残留；历史记录及许可证不作为当前页面署名使用。
