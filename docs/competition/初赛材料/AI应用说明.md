## 二、模型调用环节

### 1. 剧本生成

输入为已保存的“八仙过海”创作简报及来源、改编说明。模型生成文字剧本候选，系统保存任务和版本信息。AI 不自行确认最终剧本，由人完成题材性质、引用与表达检查后采用并确认。

### 2. 结构化分镜生成

输入为已确认剧本。模型生成包含镜头、时长、画面表达及角色／场景／道具引用的结构化分镜候选。系统执行结构与引用检查，人工继续核对、编辑复核项并确认，之后建立项目 5。

最终案例为 4 镜、30 秒、8 项资产。画面提示词是文字结果，不是已生成的图片或视频。

## 三、提示词管理方式

1. **版本管理**：业务提示词纳入管理员提示词管理，支持草稿、发布、停用和历史记录。
2. **不可变发布**：已发布版本不原地覆盖；内容调整形成新版本，避免历史任务依据被后续编辑改变。
3. **执行快照**：任务保存提示词版本、变量值或受控快照，以及模型 ID 等执行信息；旧任务不因管理员发布新版本而改变。
4. **程序约束**：权限、JSON 结构、必填字段、时长和资产引用等由程序规则校验，不仅依赖模型自觉遵守提示词。
5. **人工可控**：剧本、分镜及复核项在关键确认点由人编辑、采用；后续生成不能未经授权覆盖已确认版本。

本说明不附未核实的完整提示词正文，也不把提示词版本管理表述为自动事实裁判。正式资料包中的提示词版本与运行用量仍需团队按实际记录复核。

## 四、人工审核环节

| 环节 | 人工工作 | 目的 |
| --- | --- | --- |
| 简报与资料 | 选择蓬莱地方文化来源，确认八仙过海为民间传说 | 限定来源支撑范围，区分事实与创作 |
| 剧本确认前 | 补充题材性质说明，核对引用来源 ID | 防止将原创情节、对白写成史实 |
| 分镜确认前 | 核对角色、场景、道具引用并编辑复核项 | 保证镜头与资产对应，减少结构错误 |
| 资产口径 | 将群像明确为“其余六仙”，与铁拐李、何仙姑合计八位 | 防止人物重复或数量不一致 |
| 项目与导出 | 采用并确认剧本、分镜，建立项目，检查六 Sheet Excel | 保留人工决策及可追溯交付物 |

来源复核确认引用是否恰当，不表示政府网站为原创剧情背书。正式资料包仍须团队进行事实审核。

## 五、能力边界与合规说明

- 图片、视频尚未在应用内开放，本案例没有应用内媒体生成结果。
- Excel／ZIP 不是一键成片；当前不自动完成剪辑、配音、配乐或视频合成。
- 尚未开展非团队成员试用和相同任务的人工对照，不能声称效率提升百分比。
- 具体导出文件、截图和本机运行配置不进入仓库；评审展示须使用团队核验后的环境与历史记录。
