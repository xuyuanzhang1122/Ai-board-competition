## 本批变化

- 增加 `TextGenerationProvider`、中立结果对象和 MiMo/DeepSeek 官方适配实现。结果包含供应商、实际响应模型、请求 ID 和可空的用量，不再向业务层暴露旧客户端 DTO。
- 文本生成、工具箱文本服务、两处剧本拆分均转入新接口；删除 `GeeknowClient` 中的文本执行、供应商分流与文本 DTO，删除旧 Agnes/DeepSeek 配置类。该客户端的图片实现仍留待后续替换。
- 文本默认 ID 改为 `deepseek-flash`。后端请求仅接受 `deepseek-flash`、`deepseek-v4-pro`、`mimo-v2.6-pro`；`AiTextService` 的提交方法在创建任务、扣积分前拒绝旧 ID、未配置能力和不合法参数。
- `AiTextService` 的独立执行器续跑时使用已保存的模型字段，不从新请求或新默认值推断历史模型；旧模型任务标记失败，不再调用旧接口。`PARSE_TEXT` 的批量/MQ 包装路径尚未冻结模型，仍先创建外层任务、再调用文本服务，须在发布前补齐。全部参数快照、在途账务对账尚未在本批实现。
- 任务结果增加 `provider`、`upstreamModel`、`providerRequestId`、`usageKnown`。旧接口中未知用量仍显示 0，但 `usageKnown=false` 明确说明它不是实测零用量。

## 供应商配置与请求约束

独立配置前缀为 `ai.text-providers`，两家默认均关闭。旧 `ai.deepseek`、`ai.agnes` 或旧客户端密钥不会自动迁入。配置样例见 `infra/competition/.env.text-providers.example`；它只包含文本设置，不能单独作为完整后端启动配置。

示例采用 dotenv 支持的点分属性名。独立启动文件还必须包含隔离后的数据库、存储、队列、端口和 JWT 设置；可以通过 `APP_DOTENV_PATH` 指定完整文件。未完成真实调用及任务兼容验收前保持 `enabled=false`。

| 供应商 | 支持的官方入口 | 当前参数 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `/chat/completions`，限制 `max_tokens`，关闭思考，非流式 |
| MiMo | `https://api.xiaomimimo.com/v1`、匹配订阅凭据的 `https://token-plan-cn.xiaomimimo.com/v1` | `/chat/completions`，限制 `max_completion_tokens`，非流式 |

接口依据及读取限制见 [新模型接入核验](./新模型接入核验.md)。本批不宣称工具调用、多模态或 Agent 已接通。

适配器限制输出为 1—32768 token；默认仍为业务配置的 4096。连接/响应超时分别为 15/90 秒。生产传输使用 Apache HttpClient 5，显式关闭自动重试和重定向；拒绝任意代理地址，不切换供应商或旧域名；异常不携带上游响应正文、请求头或原始异常详情。空结果、非法 JSON、截断结果不记为成功。相关开关依据：[Apache HttpClientBuilder](https://hc.apache.org/httpcomponents-client-5.2.x/current/httpclient5/apidocs/org/apache/hc/client5/http/impl/classic/HttpClientBuilder.html)。
