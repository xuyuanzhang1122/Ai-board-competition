# AI-board项目初设想
* 本文档用于构想将AI-board(后文简称本项目)特色化改为一个适用于AI创新大赛赛道三的项目，基本做到资料及授权来源输入 → 受众／渠道／传播目标选择 → 基于蓬莱知识的故事与分镜生成 → 事实和素材来源复核 → 人工修改留痕 → 生成与导出 → 案例效果对比

---

## 后端接口统一化
* 方便管理以及计费
- 将所有的原有模型上游全部删除替换。
    暂定改为：
    1. 多模态对话，文字处理模型，同时使用[小米mimo](https://mimo.mi.com/docs/zh-CN/quick-start/summary/first-api-call)V2.6系列，以及[DeepSeek](https://api-docs.deepseek.com/zh-cn/guides/vision)DeepSeek-V4.1-Flash.
    2. 照片生成模型，采用[豆包seedream5.0-flash](https://console.volcengine.com/ark/region:cn-beijing/docs/ark/image-generation-api?lang=zh)模型，以及[可灵](https://www.klingai.com/document-api/api/image/3-0-omni/image-generation)
    3. 视频生成模型，采用[豆包seedance2.5](https://ark.volcengine.com/region:cn-beijing/docs/ark/seedance-2-5?lang=zh)和[可灵](https://www.klingai.com/document-api/api/video/3-0-omni/image-to-video), ~~注意，由于豆包需要账户余额>=200元才能开通API，所以先适配~~
## 部分功能重构
* 由于本项目原始使用需求中，导入的Excel表格是已经提供好的，但为了比赛需求，需要更改功能需求
- 将首页***工具箱***更改为***头脑风暴***
    - 使用构想：通过提示词以及脚本约束，实现用户输入请求‘我想做一个八仙过海的视频，来宣传蓬莱阁’，那么这个不能是纯Chat模式的AI，打造为*agent*模式,通过`sandbox`进行能力约束后，提供一个小环境，使之可以执行允许的脚本以及[web_search](https://docs.firecrawl.dev/introduction)等工具，制作大纲以及剧本。
- 增设***落笔生辉***工具栏，在***工具箱***页面认定好的大纲，可以告诉AI，转入***落笔生辉***，落笔生辉里就会采用预处理好的提示词以及脚本生成分镜（也就是可以导入到分镜里的那种分镜级别的Excel），可以选择导出或者一键转入到新建项目中，开始项目创作。
    > 提示词以及脚本约束可能需要复刻之前的一个小项目，但不完全，剧本格式内容以及怎么处理，暂时没想好

## 针对性大赛功能释放
- 在初赛 -> 复赛的由浅入深的赛制和赛题里，对于项目功能展示需求也是不同的，在初赛仅需要提交视频以及讲解，那么实际上链路跑通即可，并且要把剧本制作时期的提示词和模板基本固定为特色化【也就是在头脑风暴会被限制主题在烟台/蓬莱文旅特色宣传】。这个部分可以直接模块化。在复赛的需求中，有一个点，叫“本土场景向功能模块转化的设计思路”，我理解认为的是由一个局限的文旅宣传的小工具变为广泛的工具，这个就可以直接在管理员面板或者其他配置文件里留一个口，用来开启或者关闭这个按钮，实现能力的缩进或释放。此外，对于提示词prompt，需要全部改入到admin页面，有一个提示词管理界面，进行迭代管理。这也是赛题中“并附关键提示词版本迭代记录。”的需求
