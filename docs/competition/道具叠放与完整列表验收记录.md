## 改动与边界

原道具单元格只展示前三个绑定，其余只有数量提示，无法直接选中。现改为三张叠放缩略图和总数入口，悬停、聚焦或点击均能展开全部绑定项。列表可滚动，并通过 Portal 挂到表格之外，避免行和单元格的 overflow-hidden 裁切。

每项提供独立的查看与移除按钮。查看按项目道具 ID 打开既有右侧详情；移除按本镜绑定 ID 调用既有解绑接口，既不删除项目道具，也不触发详情操作。添加/绑定选择仍沿用原弹窗。

键盘聚焦入口展开，Tab 或向下键进入第一项，Shift+Tab 可返回入口，Escape 或收起按钮关闭并返回入口。点击保持展开，修复了悬停打开后触发默认 toggle 可能立即关闭的问题。鼠标移开延迟收起，焦点在入口或浮层内时保留。

此修改不开放图片/视频模型，不代表整个 M4 或 R06 的五类生成面板统一已完成。
